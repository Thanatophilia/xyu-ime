# 中文组合态行为表

代码基线：`3553ab5`（D2）。本表描述 XyuImeService 在“有未提交中文组合”时的既定行为，作为回归和验收依据。行为来自当前实现与既有测试；如产品规则调整，先改本表、再改代码和测试。

## 1. 组合的生命周期

| 事件 | 行为 | 依据 |
|---|---|---|
| 输入字母/撇号 | 进入组合（requestRime PROCESS_KEY），预编辑显示在独立悬浮编码，候选栏显示候选 | ImePhase3Test / KeyboardView |
| 选词（点候选） | 按全局索引提交候选文字，组合结束或按 Rime 结果延续 | SelectCandidate |
| 删空拼音 | 组合结束，候选栏消失；不删除已上屏正文 | 候选长按删空测试 |
| 编辑框切换/输入会话变化 | 旧组合结束，未提交拼音保留在原框（平台提交行为），绝不提交到新框 | D2 延迟切框测试 |
| 语言切换（中文→英文） | 有组合先按“提交原始拼音”结束再切换；延迟未回的先作废 | D2 延迟切语言测试 |
| 隐藏键盘/应用离开 | finishComposingText + resetChinese，无残留窗口 | pauseViewLifecycle |

## 2. 组合态下的按键

| 按键 | 有组合 | 无组合 |
|---|---|---|
| 字母 a–z、撇号 | 交给 Rime 扩展拼音 | 中文模式同样进入组合；英文模式直输 |
| 空格 | Rime 选高亮候选（提交）；无组合输入普通空格 | 中文模式同上 |
| 删除 | Rime 删拼音，删空即止，不删正文 | 走 ICU 完整字符删除 |
| 回车（普通/发送/搜索/完成/下一项） | 第一次只提交原始拼音，不执行编辑器动作 | 执行编辑器动作或换行 |
| 逗号/句号（中/英） | 先提交当前候选，再插入对应中文标点 | dispatchAction Text 分支 |
| 数字、其他符号、Shift、锁定 | 按 finishRaw：先提交原始拼音，再插入/执行 | dispatchAction chinese 分支 |
| 切数字/符号页 | 页面切换本身保留组合；随后输入按上一条处理 | chinese 分支不拦截 Toggle 跳转 |
| 进编辑面板（编辑工具） | 编辑工具入口仅在无组合时显示（组合态 InfoStrip 被候选栏替换）。先以回车/选词/删除结束组合（原始拼音提交一次）再进面板；面板操作作用在已提交文本。防御路径：组合态收到编辑类动作时仍先 finishRaw 结束组合 | D2 编辑面板测试 |
| 光标移动/选区 | 组合态下先结束组合再移动；编辑器外来选择变化会让旧引擎结果失效 | onUpdateSelection |

## 3. 队列与异步

| 场景 | 行为 |
|---|---|
| 引擎响应未回时快速按键 | 按键进入动作队列；响应回来按序继续处理，最终提交恰好一次、顺序不乱 |
| 响应未回时切语言 | 切换动作按队列顺序等待当前引擎响应；先按 finishRaw 规则提交原拼音，再完成切换，旧响应不入新语言 |
| 响应未回时切换编辑框 | 系统直接回调 onStartInput：旧会话/队列作废，延迟响应被丢弃，不提交到新框 |
| 候选点击/加载带 revision | 过期修订的点击、加载结果直接拒绝 |
| 前缀加载 | 候选最多取 4096 项前缀；加载中重复请求去重 |

## 4. 编辑面板与组合的边界

- 编辑面板（光标、行首行尾、选择、全选、复制、剪切、粘贴）只作用在已提交文本。
- 有组合时进入编辑面板：先提交原始拼音，再显示面板；不重复提交、不丢已提交前缀。
- 密码框不走中文引擎：EditorPolicy 判定 sensitive 后禁用中文，键盘提示相应输入框类型。
- 剪贴板只在主动点击粘贴时读取；密码框禁止复制/剪切。

## 5. 验收口径

- 文本断言以快照（正文、组合跨度、编辑器动作列表）为准，不按词典首选词臆测候选。
- “未提交拼音留在原框”是平台行为，不算缺陷；“拼音出现在新框”才是必须为零的问题。
- 长按候选删除：删空拼音必须停止，已上屏正文保持不动。
