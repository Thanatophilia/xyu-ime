## 安装与数据

1. 从 Actions 成功运行的 artifact 解压 APK，核对 SHA256。采用原固定签名，覆盖安装阶段二版本，不要先卸载或清除数据。
2. 打开絮雨，启用并选择输入法。首次准备词库期间英文应可用，准备完成后点击小地球切换中文。
3. 开启飞行模式测试下列中文操作；APK 不申请网络权限。
4. 使用中文选词后覆盖安装下一版，检查用户数据和词频保留。清除数据会删除个人词频，仅在确认不需保留或独立测试设备上执行，再检查可重新部署。

## 中文、候选和回车

- 输入 nihao，编码应独立悬浮在键盘物理左上方；候选栏中只有候选词与右侧按钮，不再含编码行。
- 编码出现、变长和消失时，应用内容、主键盘边界、字母键与底部七键的位置/尺寸保持不变，候选栏高度不变；长编码不撑大键盘。
- 点击悬浮编码所在区域，检查下方应用仍可响应；编码不抢编辑框焦点，第一次返回应直接收起键盘和编码浮窗。此项还需在 realme 及跨应用场景复测。
- 选词、回车结束组合、切换语言/编辑框以及隐藏键盘后，不得遗留编码浮窗；点击“你好”以及空格选词，无拼音残留或重复提交。
- 输入 shi，记住顶部候选栏最后完整显示的一项，再展开：候选页应从下一项接着显示，不从第一项重复。若右边有词条只露出一部分，该词条应作为展开页首项，不能跳过。
- 候选页展开时，向左或向右滑动顶部候选栏，候选页应沿原抽屉动画向上收回，不是突然消失；候选栏继续横滑，编码和正文不变、不误选词，动画结束后才恢复字母键。
- 横滑收回后再次展开，应从候选栏新位置接续；同一接续位置只收回再展开则保留纵向浏览位置。候选页内部纵滑、左侧音节栏滚动和上下图标滚屏不应自动收回；已收起时横滑也不能误展开。改变拼音后重新计算接续位置，追加加载保持原始编号。
- 相同文字可能来自不同读音或不同候选编号，不能仅按文字判断重复；点击上下区域里的词，应提交所点的真实候选。顶部展开按钮固定，右侧上下图标继续滚动当前列表。
- 输入 n，再展开候选页：左侧显示“全部”及实际拼音/首音节（如 ni、na、ne）；点击某一音节，右侧只显示该分组候选，选中状态明显。点“全部”恢复原始候选。
- 选择拼音不提交或改写编码，不改变应用窗口、候选栏和键盘高度；点击筛选后不是首项的候选，实际提交应与该词一致。缺失拼音信息的候选仍能在“全部”找到。
- 普通键盘底部符号（!@#）键和回车键应同宽同高。输入 shi 并展开，左侧拼音区域宽度与符号键一致，右侧每个图标按键宽度与普通回车键一致；收回后两端按键尺寸恢复一致。
- 单字模式完整一行恰好五个字；切回“全部”，二至五字词按实际文字宽度紧凑换行，不能占用二至五个整列或均摊出巨大词距。试 nihao、zhongguoren 等词语和长短词混排，检查文字不挤压、不重叠、顺序不变。
- 手指上下拖动应连续查看不同候选并停在任意位置；上下图标继续滚动同一列表，不得误选或改写编码。左右栏、左下切换按钮保持固定。
- 手动拖到中间后点击右侧下箭头，应从当前位置向下滚动约一屏；再点上箭头向上滚动，之后仍可自由手动滑动。按钮和手势不应切换成不同浏览模式。接近末端继续读取更多（最多 4096 项前缀），图标在不能继续滚动的方向置灰。
- 左下固定“全部／单字”二态切换，无“词语”；右侧从上到下为删除、上箭头、下箭头、回车图标，不显示“上翻页／下翻页”文字。切换音节或字类回到该筛选开头，滚动不改变编码或原始候选编号。
- 点删除只减少当前拼音；长按连续删除，删空拼音后必须停止，不得继续删除已提交正文。右栏回车提交引擎当前高亮候选，不预测具体词条；组合结束后已提交正文前缀保留，不执行发送或搜索。
- 点右上角收回箭头恢复普通键盘；正在输入的拼音应保留在悬浮编码中，可继续修改。候选页操作不改变应用窗口、键盘高度和悬浮编码位置。
- 快速反向展开／收回、同一组合反复浏览，检查保留滚动位置；改变拼音、音节/单字筛选或结束组合时正确重置。箭头动画中开始手动拖动应立即交还滚动控制。
- 删除拼音、连续输入、中文逗号句号、切换中英文不丢字。
- 普通键盘的回车在搜索／发送／完成框：有拼音时第一次只提交原始拼音，第二次才执行对应动作；多行框第一次提交拼音，下一次换行。展开页右栏回车遵循上面的候选提交规则。
- 单独输入撇号得到字面量 '；输入 xi、切符号页输入 '、返回字母页输入 an，应保持一个 xi'an 组合。
- 中文 Shift 保留单次大写／锁定语义，产生大写前提交原始拼音；中文不应用英文自动句首大写。
