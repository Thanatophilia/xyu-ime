## 安装与数据

1. 从 Actions 成功运行的 artifact 解压 APK，核对 SHA256。采用原固定签名，覆盖安装阶段二版本，不要先卸载或清除数据。
2. 打开絮雨，启用并选择输入法。首次准备词库期间英文应可用，准备完成后点击小地球切换中文。
3. 开启飞行模式测试下列中文操作；APK 不申请网络权限。
4. 使用中文选词后覆盖安装下一版，检查用户数据和词频保留。清除数据会删除个人词频，仅在确认不需保留或独立测试设备上执行，再检查可重新部署。

## 中文、候选和回车

- 输入 nihao，编码应独立悬浮在键盘物理左上方；候选栏中只有候选词与右侧按钮，不再含编码行。
- 编码出现、变长和消失时，应用内容、主键盘边界、字母键与底部七键的位置/尺寸保持不变，候选栏高度不变；长编码不撑大键盘。
- 点击悬浮编码所在区域，检查下方应用仍可响应；编码不抢编辑框焦点，第一次返回应直接收起键盘和编码浮窗。此项还需在 realme 及跨应用场景复测。
- 选词、回车结束组合、切换语言/编辑框以及隐藏键盘后，不得遗留编码浮窗；点击“你好”以及空格选词，无拼音残留或重复提交。
- 输入 shi，横滑候选栏浏览更多候选；右侧展开按钮不随滚动移动。没有上一页／下一页按钮。
- 展开候选抽屉须向下替换整个键盘，包括全部底部七键；普通按键不可见、不可点击。候选页纵向滑动不误选词，点击选词正确；收回恢复普通键盘。
- 快速反向展开／收回、同一组合反复浏览、改变拼音、结束组合，检查动画、滚动位置与重置。
- 删除拼音、连续输入、中文逗号句号、切换中英文不丢字。
- 搜索／发送／完成框：有拼音时第一次回车只提交原始拼音，第二次才执行对应动作；多行框第一次提交拼音，下一次换行。
- 单独输入撇号得到字面量 '；输入 xi、切符号页输入 '、返回字母页输入 an，应保持一个 xi'an 组合。
- 中文 Shift 保留单次大写／锁定语义，产生大写前提交原始拼音；中文不应用英文自动句首大写。
