## 本轮实际修复

1. **横屏触控越界**：横屏紧凑键 48dp 触控扩展曾比可见键盘底部多出约 3dp，进入系统手势区。横屏键盘主体高度 191→199dp、上限 203→211dp，上下内边距 4→8dp，使最小触控范围完整落在键盘内；竖屏尺寸、七键顺序、候选规则不变。
2. **横屏候选页无法展开**：旋转后候选栏首次布局就绪时未捕获“最左首屏接续边界”，点击展开被保护条件拦截。现在点击时若边界尚未锁定，只在候选栏仍处最左端时用当前实测布局捕获一次；已横滑的位置不会被当作起点，固定接续规则不变。
3. **无障碍状态**：Shift 增加“小写／大写／大写已锁定／中文拼音”状态说明，长按动作名为“切换大写锁定”；语言键说明当前模式、长按为“选择系统输入法”；候选字类按钮朗读“切换候选字类”，状态在“全部字词候选／仅单字候选”间切换——修正了此前切到单字仍朗读“全部候选”的错误。
4. **测试设施**：新增空白 Compose 测试宿主、独立网页富文本夹具；云端先编译全部测试 APK，再跑 D4 定向用例，通过后跑全量，避免把编译错误和回归失败混在一起。

## 手机验收步骤

1. 覆盖安装 0.3.93（同一固定签名），打开应用确认版本 0.3.93（93）。
2. **横屏**：在任意输入框调出键盘后横置屏幕，确认字母区、底部七键、候选栏完整，底栏不侵入系统手势区；输入拼音后展开候选页，可正常展开、滚动、选词，返回竖屏后键盘恢复且可继续输入。
3. **大字体**：系统设置 → 显示 → 字体大小调到最大（或 1.3 倍档），回到输入法输入中英文、展开候选页、进入编辑面板，确认文字不重叠、按键可点、轨道不越界。
4. **常用应用**：在聊天、浏览器、备忘录中各输入一段中英文，切换应用和输入框，确认无串字、无残留编码浮窗、无键盘高度跳动。
5. **标准/抬高**：系统键盘位置分别选“标准”和“抬高”，重复第 2 步竖屏部分，确认底栏与系统切换入口不重叠。
6. **TalkBack**（设置 → 无障碍 → TalkBack 开启）：
   - Shift 朗读当前状态（小写/大写/已锁定），长按弹出“切换大写锁定”；
   - 语言键朗读当前模式，长按弹出“选择系统输入法”；
   - 展开候选页后，字类按钮朗读“切换候选字类／全部字词候选”，切到单字后朗读“仅单字候选”；音节条选中状态可感知。
7. **触控边界**：按住字母后拖出键盘再松手，不产生输入；长按删除后把手指拖出键盘，连续删除立即停止；候选页内拖动只滚动不选词。
8. 回归抽查：长按删除、连删取消、候选固定首屏接续、横滑收回、两段式回车。
