## 本轮变更

1. 应用首页改为当前能力说明：离线简体全拼、中英文切换、独立悬浮编码、候选页、基础编辑；移除"PHASE 02 / 基础编辑测试版 / 当前仍为 English"旧文案；保留启用/选择输入法和版本信息。
2. 试打区新增四类场景：
   - **中文长句**：多行中文输入，可填入人工中文样例，检查逐词选择、长句连续输入、光标和选区操作；
   - **发送**：本地计数，验证"有拼音时第一次回车只提交拼音、第二次才触发动作"，不发送真实消息；
   - **下一项/上一项**：回车在 A/B 两框间移动，动作只本地计数；
   - **双输入框**：直接点按切框，检查未提交拼音不会串到另一输入框。
3. 试打内容与动作计数在切换测试类型、收起键盘或应用离开前台后清空；不保存、不上传、不记日志。
4. 每个编辑器动作（搜索/完成/前往/发送/下一项/上一项）显示"动作已收到 · 本地第 N 次"，可核对触发次数。

## 手机验收步骤

1. 覆盖安装 0.3.74（同一固定签名），打开"絮雨输入法"应用。首页应显示"离线中英文输入"和"离线简体全拼 · 英文直输 · 基础编辑"，版本号为 0.3.74（74）。
2. 试打区 → **中文长句**：点按小地球切到中文，输入 nihaozhongguo，逐词选择候选后继续输入；再点"填入中文样例"，移动光标、选字删除，确认无丢字、无重复提交、悬浮编码与候选栏正常。
3. 试打区 → **发送**：输入英文字母后按回车，应显示"发送动作已收到 · 本地第 1 次"；再按一次回车显示"第 2 次"。切到中文输入拼音后按回车，第一次应只提交拼音、不计数；再按回车才计数一次。
4. 试打区 → **下一项/上一项**：在 A 框输入后按回车，焦点移到 B 框并显示"下一项动作已收到 · 本地第 1 次"；在 B 框按回车回到 A 框并显示"上一项动作已收到 · 本地第 2 次"。
5. 试打区 → **双输入框**：在 A 框输入拼音（不选词），直接点 B 框；未提交拼音保持留在 A 框，B 框不受影响，随后在 B 框输入正常。
6. 切换到其他测试类型，再切回：之前的试打内容和动作计数应已清空。
7. 在系统键盘位置分别选"标准"和"抬高"，重复第 2 步一次，确认底栏、候选栏和悬浮编码位置正常。
8. 回归抽查 0.3.72 基线：候选栏最左端展开、横滑收回动画、音节筛选、单字五列与词语混排、等宽侧栏。
