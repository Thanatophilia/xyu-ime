# 阶段四 D5 · 符号页重排任务书

编写日期：2026-11-18。设计基线：**0.3.93（D1—D4 已实机验收通过）**，代码 `c7466aa`。D5 最终验收版：**0.3.106**，代码 `1d50bc8`，云端全绿，用户于 2026-11-19 确认“还不错，测试没问题”，D5 实机验收通过。本任务书记录目标、约束、实施方法和交付结果。

## 一、背景与目标

用户在阶段一验收后即提出“希望改变符号页布局”，当时明确先完善基础功能、不是现在。D1—D4 完成后，符号页成为下一项明确工作。

**目标**：把符号页从“一组固定的英文符号”改为**覆盖中文日常输入、分类清晰、可预期**的符号键盘，同时不改变底部七键、候选页、悬浮编码和既有输入规则。

**成功标准**：用户能在符号页一次找到并输入常用中文标点（、。《》…… “”等）与常用英文/数学符号；分类逻辑不用猜测；中文组合态下符号输入结果正确；ASCII 输入框不出现中文标点；横屏与 1.5 倍字体下完整可用。

## 二、当前实现盘点（事实）

- D5 实现前基线：底部七键“！﹫#”键切换；旧符号页返回用面板内“ABC”。D5 已重排为顶部分类键、可滚动符号网格和一格浮动删除键；详见本任务书末尾的实施记录。三行结构：`! @ # $ % ^ & * ( )` / `- _ + = { } [ ] | \` / `; : ' " ?` + ABC + 删除。
- 数字页同样三行，第三行按钮随输入框类型变化（`numberKind`：phone/decimal/signed/datetime/普通）。
- 每行 10 列；普通键高按行权重大致 34–47dp；符号键的**显示标签就是实际插入字符**（KeyFace(text, text)）。普通键盘逗号、句号键直接发 `state.comma/period`（ASCII 框里是 , .）。
- 中文组合态规则（已由 D3 测试锁定）：组合中按符号先提交原始拼音、再插入字符；逗号/句号是“先提交候选、再插入中文标点”的独立路径。
- 键盘几何（等宽两端、七键顺序、候选页与编辑面板结构）已由多轮验收固定，属于不可回归项。
- D5 目标是补齐并数据化中文标点：、。《》〈〉【】「」『』……——，同时保留完整 ASCII 与数学/单位组；实现候选版本已包含这些数据。

## 三、范围

**要做**：

1. 完整字符盘点：去重、补齐中文常用标点与常用数学/单位符号。
2. 分组与布局样稿（HTML 或截图），用户定稿后再实现。
3. 符号数据与界面分离：字符、分组、顺序用数据描述，`SymbolsPanel` 只渲染。
4. 分类切换入口（如需）与返回字母页路径。
5. **按输入框类型切换中/英符号组**：普通文本框给中文标点组；邮箱/网址/密码等 ASCII 框给 ASCII 组；数字框不受影响。
6. 组合态联动验证：组合中按符号沿用“先交原拼音再插符号”；符号页内的逗号、句号行为明确且可测。
7. 横屏、1.5 倍字体、TalkBack 下的可用性验证。

**不做（本批外）**：Emoji/表情面板；长按符号弹层；最近使用符号；自定义符号排序 UI；云符号库；九宫格/语音/滑行。这些在稳定版之后另议。

## 四、要注意什么（约束与坑）

0. **底栏首键双形态**：「！﹫#」在字母/数字页进入符号页；进入符号页后同一键位显示「ABC」并高亮，点击返回字母页。该键的宽度、位置不动；返回时恢复「！﹫#」标签与原有高亮逻辑。数字页「123」键行为不变。
0b. **手势冲突**：符号区上下滚动与左右切组必须按主方向区分（横向位移超过阈值且大于纵向时才切组）；横滑不插入任何字符、不触发删除；切组后滚动位置回到该组顶部。切组只换内容，不提交、不改键盘高度。
1. **标签=插入值**：符号键显示什么就插入什么。换行、制表等不可见字符不得用文本标签直接表示；编辑动作与字符要分开描述。删除键沿用候选页删除图标与长按连删语义或明确取消，实现时二选一并测试。
2. **`×` `÷` `−` 等是全角/数学字符**：数学乘除用 U+00D7/U+00F7，不是字母 x 或斜杠；负号场景要用 ASCII `-`。样稿需逐字符标注码点，避免看起来一样但插入错误的字符。
3. **ASCII 与中文标点不得混**：邮箱、网址、密码、数字密码框（`EditorPolicy.asciiPunctuation`）必须保持 ASCII 标点。符号页切换逻辑要覆盖这些框，并在离开时恢复。
4. **组合态联动**：中文组合中从符号页插入字符 = `finishRaw` 先提交原拼音再插字符；逗号句号仍是先选词再标点。两套路径都要有测试，不能只测无组合。
5. **等宽关系**：普通键盘“！﹫#”与回车同宽、候选页两侧与对应键等宽，是已验收规则；符号页改动不得改变这些宽度计算（`KeyboardGeometry` 常量与七键底栏不动）。
6. **两处入口状态**：底部七键的“！﹫#/123”高亮状态按页显示；符号页内“ABC”返回必须回到离开前的字母页状态（不重置 Shift/组合）。
7. **键盘高度不跳**：切页只在固定高度内换内容，不改变键盘外框尺寸，不顶起应用。
8. **无障碍**：每个符号键要有可朗读名称（空白/不可见符号需要文字名），分类按钮要有选中状态。
9. **大字体**：1.5 倍字体下 10 列键宽可能挤字，需缩排或截断策略，不能重叠或不可点。

## 五、要避免什么（红线）

1. 不借 D5 动七键顺序、空格宽度、回车动作或底栏尺寸。
2. 不重做候选页、悬浮编码、编辑面板；这些已验收，只允许回归，不允许顺带改。
3. 不把“最近使用/长按弹层/Emoji”混进本批，避免范围和评审失控。
4. 不引入新的按键手势语义（长按仍只用于已有功能），符号键先做单击插入。
5. 不把符号数据写死在 Composable 里（保持单一数据源，便于测试与后续排序）。
6. 不在发布 APK 中保留任何调试用符号实验入口。
7. 样稿未经确认前不合并代码；确认后不夹带范围外改动。

## 六、怎么做（实施步骤）

**WP1 布局与字符集（按用户 2026-11-18 的 v2 手势面板要求）**

符号页结构（v5，用户 2026-11-18 确认“删除键只做一个格子大小、浮着遮住一个符号；不做整行、不做强调样式”）：

```
┌ 信息条：絮雨 · 符号      ● ○ ○ 1/3      编辑 ┐  ← 圆点指示放这里，不遮符号
│ 分类键：中文标点 | 英文符号 | 数学单位 │   ← 面板顶部一行，显示“当前”态
│ 符号区：三行完整可见，8 列网格         │
│         上下滑动浏览本组全部符号        │
│         左右滑动切换相邻分类（循环）    │
│                      [⌫]← 一格大小的删除浮层，盖住网格右下角一个符号
└ 底栏：ABC | 123 | ，| 空格 | 。| 🌐 | 回车 ┘  ← 首个键在符号页显示“ABC”，点击返回字母页
```

- 删除键＝普通键样式（不做强调色、阴影、加粗），尺寸约一格，浮层叠在网格右下角格位、遮住一个符号；被遮的符号滚动后即可露出，网格内容底部留出该高度的空白。
- 圆点指示（● ○ ○ 1/3）移入信息条中部，不再占网格区域；组名由顶部“当前”高亮体现。
- 删除键视觉为一格浮层，分组圆点在信息条中显示；真机触摸验收必须确认轻点一次删除一个、长按连续删除、抬手停止。

- 字符集不再受“每屏 20 格”限制，按滑动浏览收纳全部常用符号（用户可增删）：
  - 中文标点 **27**：， 。 、 ； ： ！ ？ “ ” ‘ ’ （ ） 《 》 【 】 「 」 〈 〉 『 』 … — ～ ·；
  - 英文符号 **26**：! @ # $ % ^ & * ( ) - _ = + / \ ' " ? ~ { } [ ] | `；
  - 数学单位 **22**：+ −(U+2212) × ÷ = ≠ ≈ ≤ ≥ ± % ‰ ° ℃ € ¥ £ $ √ ∞ π µ。
- 码点与名称见样稿表格；实现时每组按数据表生成。

## 十、D5.1 符号扩充（2026-11-19，待实机）
