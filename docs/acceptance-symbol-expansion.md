# 阶段四 D5.1 · 符号扩充 · 手机验收

版本：**0.3.112（112）**；代码提交 `9401c77`；[Actions #112](https://github.com/Thanatophilia/xyuime/actions/runs/44438180806) 全部成功。

## 背景

0.3.106 的符号页已实机验收通过，但日常使用中发现符号数量不足。为扩展覆盖面，调研了以下公开输入法的符号实现方式：

- FlorisBoard：CJK/西文符号布局、长按相关变体、扩展符号页；
- HeliBoard：基础符号、更多符号、电话符号分布局；
- OpenBoard：基础符号页与“更多”符号页、单键扩展候选；
- AnySoftKeyboard：常用符号页 + 备选符号布局；
- Fcitx5 Android：分组符号选择器、标点映射与插入分离。

据此采用“保持前三组、新增扩展组，低频与专业符号放扩展”的方案，避免把常用页面挤密。

## 本轮变更

- 符号分组由三组改为四组：中文标点、英文符号、数学单位、**扩展符号**。
- 字符数：中文标点 27、英文符号 30、数学单位 22、扩展符号 93。
- 英文组新增可直接插入的 `: ; < >`；逗号和句号仍保留在底栏，因为它们会按输入框类型和中文组合走“先提交候选再插标点”的既有路径，放入符号组会出现“键面与实际结果不一致”。
- 扩展组覆盖：方向箭头、希腊字母、扩展数学符号（∑∫∂∇∈∩∪等）、分数与上下标、地区货币、正反问号与引号变体、CJK 常用符号（※〃々〆〒〇）、剑标/章节/段落/编号/版权商标、图形与音乐符号。
- 保留已验证的交互：8 列网格、上下滚动、左右跟手分页、松手吸附、双向循环、一格删除浮层、信息条分组圆点、底栏 ABC、ASCII 输入框默认英文组。

## 手机验收步骤

1. 覆盖安装 0.3.112，确认版本号 0.3.112（112）。
2. 打开符号页，顶部应有四组分类；信息条圆点为 ● ○ ○ ○，共 4 组。
3. 左右滑动切到“扩展符号”，检查箭头、希腊字母、数学、货币、版权等分组；点击若干字符，确认实际插入与键面一致。
4. 切到“英文符号”，确认 `: ; < >` 的插入结果，与底栏逗号、句号各自的既有行为不冲突。
5. 上下滚动扩展组，确认高频符号无需长按即可找到；被右下角删除浮层盖住的符号滚动后仍可选择。
6. 邮箱/网址框打开符号页默认英文组；手动切中文标点后插入顿号，结果应归一为半角逗号。
7. 回归抽查：中文组合 `nihao` + 符号先提交拼音；左右切组跟手并吸附；单格删除单击/长按；底栏 ABC 返回字母页。

反馈请注明版本 0.3.112 和实际操作。若某类符号仍不够，请注明“需要哪些字符、期望放在哪一组”，下一轮按使用频率调整或替换。
