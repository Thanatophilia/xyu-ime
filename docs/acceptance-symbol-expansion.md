## 新分类

八个分类：**常用 / 最近 / 中 / 英 / 数 / 箭头 / 序号 / 角标**。

- 分类条为横向滑块，一次显示 5 个，其余向左滑动分类条即可看到；网格翻组时分页器同步让当前分类滚入可见区。
- **常用**：人工挑选的 35 个日常高频符号（中文标点 + 常用 ASCII + 度/摄氏/对勾）。
- **最近**：按使用时间倒序，最近打过的符号在最前；本地持久化，重启输入法仍保留；最多记住 60 个。空时显示“还没有最近使用的符号”。
- **中** 33 / **英** 52 / **数** 59 / **箭头** 18 / **序号** 30 / **角标** 31。
- 逗号、句号仍留在底栏处理输入框与组合态的转换路径，不在符号组内。

## 手机验收步骤

1. 覆盖安装 0.3.114，打开符号页：默认显示“常用”；分类条同时显示 5 个，向左滑动分类条可看到后面 3 个。
2. 切到“最近”：首次应显示空提示；回到“中”插入顿号、书名号等 2–3 个符号，再看“最近”，最新插入的应排第一。
3. 重启键盘或重新聚焦输入框后，再打开“最近”，验证记录仍在。
4. 检查“箭头 / 序号 / 角标”三组的字符与插入结果；中英数三组保持原有覆盖并已扩充。
5. 左右滑动网格切组时，分类条应跟随滚动；上下滚动、删除浮层、ABC 返回、跟手吸附保持原样。
6. 邮箱/网址框默认“英”组；组合态插入符号仍是先提交拼音再插符号。
