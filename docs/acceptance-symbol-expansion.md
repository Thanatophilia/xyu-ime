## 本轮需求与实现

用户确认采用 CyIME 的处理方式：**保留默认松手惯性，关闭键盘内边缘拉伸回弹**。

- 新增 `KeyboardOverscroll.kt`，在 `XyuKeyboard` 入口使用 `CompositionLocalProvider(LocalOverscrollFactory provides null)`。作用于键盘后代：符号网格、分类条、候选栏、展开候选页等；应用首页/试打页不受影响。
- 符号纵向网格仍用 `ScrollableDefaults.flingBehavior()`；没有自定义速度缩放、90ms/16dp 曲线、延迟启动或强制松手即停。
- 左右 `HorizontalPager` 跟手和松手吸附动画参数不变；关闭越界效果不等于关闭翻页吸附。
- 八组字符、最近符号持久化、分类条五格可见且仅手动横滑、单格删除、ABC 返回以及输入规则不变。
- 此改动对齐了禁回弹配置，不能据此保证所有机型上的延迟或手感问题都已解决；最终以实机反馈为准。

## 符号分组（保留）

八组：**常用 / 最近 / 中 / 英 / 数 / 箭头 / 序号 / 角标**。常用 35 / 中 33 / 英 52 / 数 59 / 箭头 18 / 序号 30 / 角标 31；逗号、句号继续走底栏专用路径。

分类条一次显示 5 个，可手动横滑找其余分类；点击分类或左右翻组不自动带动分类条。最近按使用时间倒序、本地保存，上限 60，重复使用移到最前。

## 手机复测（待用户确认）

1. 覆盖安装 0.3.145，不卸载、不清数据；确认八分类、最近符号仍在。
2. **边缘**：在符号组滑到顶部/底部后继续拉动，应无拉伸、回弹；松手后点一个符号，确认一次即可输入，不必等回弹结束。
3. **惯性**：在组内快速甩动，保留默认滑行减速；按住拖动仍跟手。此次不再追求缩短默认滑行时间。
4. **横向**：左右翻组仍跟手并吸附；分类条可手动横滑，点击分类后留在原位。
5. 抽查删除、ABC 返回、候选栏/展开页选词及滑到边缘后的点选，无重复提交或误删。
