## 符号分组

- 分类条为横向滑块，一次显示 5 个，其余向左手动滑动分类条即可看到；点击分类不触发自动滚动，网格左右翻组也不移动分类条。
- **常用**：人工挑选的 35 个日常高频符号（中文标点 + 常用 ASCII + 度/摄氏/对勾）。
- **最近**：按使用时间倒序，最近打过的符号在最前；本地持久化，重启输入法仍保留；最多记住 60 个。空时显示“还没有最近使用的符号”。
- **中** 33 / **英** 52 / **数** 59 / **箭头** 18 / **序号** 30 / **角标** 31。
- 逗号、句号仍留在底栏处理输入框与组合态的转换路径，不在符号组内。

## 手机验收步骤

1. 覆盖安装 0.3.141，打开符号页：默认显示“常用”；分类条同时显示 5 个，其余分类可手动横滑查找，点击分类后分类条保持当前位置，不再自动滚动。
2. 切到“最近”：首次应显示空提示；回到“中”插入顿号、书名号等 2–3 个符号，再看“最近”，最新插入的应排第一。
3. 重启键盘或重新聚焦输入框后，再打开“最近”，验证记录仍在。
4. 检查“中 / 英 / 数 / 箭头 / 序号 / 角标”六组的字符与插入结果。
5. **上下滑动符号网格：手指拖动时跟手；快速甩动后保留平台默认惯性并自然减速；轻拖后就近停下。** 左右网格分页仍跟手并吸附；分类条仍只响应手动横滑。
6. 删除浮层、ABC 返回、邮箱/网址默认“英”组和中文组合插入保持原样。

反馈请注明版本 0.3.141、设备/Android 版本，以及上下滚动的实际惯性感受。
