## 手机验收步骤

1. 覆盖安装 0.3.127，打开符号页：默认显示“常用”；分类条同时显示 5 个，其余分类可手动横滑查找，点击分类后分类条保持当前位置，不再自动滚动。
2. 切到“最近”：首次应显示空提示；回到“中”插入顿号、书名号等 2–3 个符号，再看“最近”，最新插入的应排第一。
3. 重启键盘或重新聚焦输入框后，再打开“最近”，验证记录仍在。
4. 检查“中 / 英 / 数 / 箭头 / 序号 / 角标”六组的字符与插入结果。
5. **上下滑动符号网格：手指拖动时跟手；快速甩动后应仍有一小段滑行，但明显短于默认；轻拖后基本就近停下。** 左右网格分页仍跟手并吸附；分类条仍只响应手动横滑。
6. 删除浮层、ABC 返回、邮箱/网址默认“英”组和中文组合插入保持原样。

反馈请注明版本 0.3.127、设备/Android 版本，以及上下滚动是否还会惯性滑行。
