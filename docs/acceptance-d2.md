## 手机验收步骤

1. 覆盖安装 0.3.82（同一固定签名），打开应用确认版本 0.3.82（82）。
2. 试打区 → **中文长句**（或任意文本框）切中文：快速连打 nihaozhongguoshijie（不经停顿），结束后逐词选词或回车提交。确认拼音、候选同步，最终正文恰好一份、无重复、无乱序。
3. 输入 n（不选词），马上点按小地球切英文：拼音应作为原始文本先上屏，键盘切到英文，无残留候选；继续输入正常。
4. 输入 n（不选词），直接点另一个输入框：拼音不得出现在新输入框；切回原框可见拼音以原始文本留在原框（平台行为）。
5. 输入 nihao 后按回车提交，点“编辑”进入编辑面板，点几次光标左移，回键盘继续输入拼音并提交：光标位置正确、无重复提交、无丢字。
6. 输入 shi 后展开候选页，长按右侧删除键直到拼音删空：候选页收起，已上屏正文（如第 5 步的 nihao）保持不动，删除不越界。
7. 快速展开/收回候选页、连续删除、旋转（可选）、切输入框后重开键盘：无残留浮动编码、无串框文本。
8. 抽查回归：搜索/发送框两次回车行为、候选页固定首屏接续与横滑收回、单字五列与词语混排。

反馈请注明版本 0.3.82、输入框类型、操作顺序、期望与实际。本轮验收通过后进入 D3（特殊输入框、中英文与标点规则）。
