## 已确定的交互

- 展开／收回采用宽口、圆端点折线图标，保持固定点击区。
- 左栏是实际候选首音节筛选，包含“全部”，选中项有底色；首音节栏可独立滚动。左栏宽度与普通键盘的符号（!@#）键一致；普通符号键与回车键同宽同高，左右侧栏采用同一个边缘按键宽度规则，不再分别写死为 64dp / 56dp。
- 左下固定“全部／单字”二态切换，无“词语”模式。单字按完整候选 Unicode 码点数为 1 判定，按钮触控区域完整留在左栏内。
- **单字模式**保留五个等宽列，完整一行五个字。“全部”模式的词语改为实际文字宽度加 12dp 总留白，紧凑地依次换行；最小宽度约为候选区五分之一，超长词封顶为候选区宽度。撤回按字数占整列的规则，二字词不再占两个完整单字格，三至五字词也不会被强制撑满一行。按原生顺序及全局索引混排，仍使用连续懒加载列表，不增加固定分页。
- 右栏从上到下固定为删除、上箭头、下箭头、回车折返图标；右栏及四个按钮实际表面宽度均与普通键盘回车键一致，左右对齐，无额外横向内缩。按钮没有可见文字，保留无障碍说明；上/下图标从当前滚动位置平滑移动约 85% 视口，保留重叠作为视觉参照，不创建固定页码，不向 Rime 发送翻页键或改变编码/高亮。
- 手动拖动和按钮共享同一个 LazyGridState，可自由交替；手指开始拖动会取消正在执行或等待加载的快捷滚动。切换音节/字类或输入变化时回顶，重复点击当前音节也回顶，同一组合收回再展开保留滚动位置。
- 接近已加载网格或音节列表末尾继续读取候选前缀。下箭头位于已加载末端时会请求加载，候选增加后继续滚动（等待有界），不可滚动的首/末端图标置灰。沿用最多 4096 项候选前缀上限，空筛选会继续寻找后续候选。
- **候选栏与展开页接续**：展开页从顶部候选栏最后完整可见项的下一原始编号开始，不重复已经完整显示的候选；右边只露出一部分的词仍作为展开页首项。开始横滑候选栏时同步更新接续位置并回到新起点；接续位置不变的收回再展开保留纵向位置。以真实布局尺寸判断完整显示，不能用裁剪后的触控区域；不得按文字去重，相同文字仍保留各自原始编号。追加候选保持已有编号和可见锚点，新输入修订重新计算。筛选作用于接续后的候选。
- 点击候选按原始全局索引提交并检查修订；右栏回车提交真实高亮候选，越界则不执行，保留 candidateSession 保护且不触发编辑器发送／搜索。
- 删除只编辑当前未提交拼音，支持长按连删，删空后不波及已提交正文。
- 独立悬浮编码保持在键盘物理左上方；展开页继续替换整个下方键盘，包括原底部七键，应用窗口和 IME 布局不变。
- 本轮只修改 app 模块和测试，不改引擎、资源、方案与构建。旧版本 0.3.55 的三态类型／清空／返回交互由上述已确认布局替代。

## 暂缓的候选页能力

- 长按候选查看详情、把候选标记为不再推荐、删除误学词等能力需要区分普通词典候选和用户学习词。当前引擎桥接未暴露学习词删除接口，且误删普通词库候选没有意义；应单独设计确认交互和引擎接口，不在本轮用假删除实现。
- 滑行输入、语音、Emoji 面板、九宫格属于后续阶段，不在本页范围。

## 读音来源与边界

通过 librime 公共候选迭代 API 同时复制 `text` 和 `comment`，以成对数据交给 Kotlin，空注释保留空槽，避免索引错位。内置全拼方案开启 `spelling_hints` 与 `always_show_comments`，由 script_translator 从词典 syllable code 生成实际拼写；不对汉字另做猜音，也不把输入串复制到每个候选上。

拼音栏按候选首音节分组，例如 `ni hao` 归入 `ni`。这属于对真实候选的首音节筛选，并非九宫格消歧，也不是逐音节改写 Rime 的输入。缺少拼音信息的候选仍可在“全部”找到。

读音支持已在 0.3.54 同步更新方案版本与资源哈希，并通过部署事务保留用户目录；本轮不更改方案或资源，继续保留升级失败恢复机制。

## 回归重点

- 普通符号键和回车键真实可见/触控宽高相等；候选左右栏及右侧每个功能键与对应普通键实测等宽并对齐，允许像素取整误差 1px。左下类型触控区域不越出侧栏。
- 单字模式所有完整可见行恰好五个等宽单元；“全部”模式以实际文字宽度验证二字词一行至少三个、三至五字词不过度撑宽、长短词依序紧凑换行。相邻项不重叠，不把行尾空白均摊为巨大词距；超长词不越过候选区边界。
- 实际布局测试使用独立文字测量，而非复用生产宽度函数作为预期。单字五列、普通按键展开/收回尺寸和原连续手势/图标滚屏均继续通过。
- 接续联动测试独立读取完整候选栏布局和展开页首项：右侧半露词条必须作为首项，完整显示的前缀不能重复；横滑候选栏（含反向）后首项跟随更新，同一接续位置收回重开保持纵向位置，追加候选不重置，新输入修订重新计算。相同文字的选词必须回传各自原始编号。
- 多读音候选使用当前引擎路径的真实拼写，扩展加载保持文字/拼音一一对应。
- 筛选后选中非零全局索引的词条，实际提交与所见文字一致。
- “全部”恢复首屏候选；遍历连续滚动视口（允许相邻屏重叠）后，以原始索引和文字核对音节/单字筛选子集。
- 真实手指拖动必须改变候选位置；手动停在任意位置后上下图标继续移动列表；使用图标后仍可手动拖动，无固定九项页限制。
- 右栏四键按指定顺序且都呈现图标，无可见“上翻页／下翻页／回车”标签；保留操作描述，左下类型按钮始终固定。
- 手势与滚屏不得选词、提交、露出普通键、收起候选页或改变应用窗口和编码；回车仍验证组合结束、已提交前缀保留、编辑器动作为空。
- 普通键盘与底部七键在展开页不可见；收回恢复；既有独立悬浮编码、返回、编辑功能回归继续通过。
