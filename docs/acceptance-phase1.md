## 安装与启用

1. 安装同目录中的 `xyu-ime-版本.apk`，打开“絮雨输入法”。
2. 点“启用絮雨输入法”，在系统中开启絮雨。
3. 回到应用，点“选择絮雨输入法”，选择絮雨。
4. 点试打框，确认键盘弹出。首次启用的系统输入法风险提示由 Android 提供。

## 布局与高度

- [ ] 字母行按 QWERTY 10/9/7 错列排列，第三行两侧为 Shift 和删除。
- [ ] 最底部从左到右恰好七键：！﹫#、123、，、空格、。、小地球、回车。
- [ ] 空格占主要宽度，其余按键清晰、能点中。
- [ ] 系统“键盘位置→标准”时，底部按键无裁切、不覆盖手势条。
- [ ] 系统“键盘位置→抬高”时，键盘随系统上移，底部没有叠加第二段空白，系统右侧快捷切换入口可用。
- [ ] 切换标准/抬高后重新弹出键盘，布局仍正确。测试后恢复自己的位置设置。
- [ ] 横屏可输入，不进入占满屏幕的提取编辑模式；竖屏恢复正常。

## 输入与手势

- [ ] 输入 `hello xyu`，空格、逗号、句号正常；底栏标点遵照标签输出中文标点，密码框自动使用 ASCII 标点。
- [ ] Shift 点按后输入一个大写字母，再回到小写；长按锁定大写，再点按可取消。
- [ ] 删除点按删除一个 Unicode 码点，不产生半个代理字符；选中文本后删除能清除选区。
- [ ] 长按删除连续删除；松手、收起键盘、切换应用后立即停止。
- [ ] 123 打开数字页，再点回字母；！﹫# 打开符号页，再点回字母。
- [ ] 小地球点按提示“当前仅启用 English”，保持在絮雨，绝不切换大小写。
- [ ] 小地球长按打开系统输入法列表；松手不再触发短按。
- [ ] 在列表中选其他输入法，再通过系统列表切回絮雨。

## 编辑框兼容

- [ ] 应用试打区“文本”：回车插入换行。
- [ ] “搜索”：回车显示搜索并触发“搜索动作已收到”。
- [ ] “数字”：默认打开数字页。
- [ ] “密码”：字符直输，不记录、不产生联想或学习数据。
- [ ] 在聊天、浏览器网页和备忘录分别试打，选区替换、快速连续按键正常。
- [ ] 反复打开/收起十次，切换应用后没有白屏、黑屏、旧按键继续输入。
- [ ] 后续同签名版本能直接覆盖安装，输入法启用状态不丢失。
