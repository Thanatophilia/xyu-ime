# 絮雨输入法 · Xyu IME

以 Jetpack Compose 绘制键盘，自行实现 Android 系统输入法前端。阶段三已接入离线 Rime/librime 简体全拼；D1—D5 已实机验收通过；D5.2 符号分类重排候选版为 **0.3.127**：常用/最近/中/英/数/箭头/序号/角标，最近符号按使用时间排序；分类条五格可见，点击分类不自动滚动（等待实机验收）。0.3.51 核心显示效果已获用户认可；阶段三候选基线 **0.3.72** 把展开页接续固定在候选栏最左端首屏末尾之后，横滑候选栏仍沿原抽屉动画收回，但不再改变接续起点。词语紧凑混排、单字五列、侧栏等宽、连续滑动与独立悬浮编码保持。云端验证通过；2026-11-18 用户明确确认 0.3.72 上一轮改动实机验证无问题，作为当前开发基线。完整路线与后续安排见[开发路线](docs/roadmap.md)。

后续执行细节见[完整实施方案](docs/implementation-plan.md)、[测试与验收矩阵](docs/verification-plan.md)和当前 [D6 升级恢复任务书](docs/d6-taskbook.md)，包含工作包、实施顺序、交付标准及测试环境。

### 已交付功能

- Android 8.0（API 26）及以上；compile / target SDK 36。
- QWERTY 字母区 10 / 9 / 7 错列，Shift、删除位于第三行两侧。
- 底部始终七键：`[！﹫#] [123] [，] [空格] [。] [小地球] [回车]`。
- 支持英文直输、Shift、长按 Shift 大写锁定、长按删除连删、数字页、符号页。
- 小地球：点按切换内部语言，首版仅 English 时提示并保留英文；长按打开系统输入法选择器。
- 根据编辑框类型进入数字页，按编辑器约定执行搜索、完成、发送或换行。
- Compose 生命周期由输入法服务管理；使用标准输入法窗口，不添加悬浮窗。
- 无网络权限、不记录输入内容。

## 第三阶段 · 0.3.72 本轮中文候选交互实机验证通过

- 候选交付版本：**0.3.72**（versionCode 72），代码提交 [`b3b0e05`](https://github.com/Thanatophilia/xyu-ime/commit/b3b0e0521897d59543b4047d26f39e3985202561)，Actions [#72](https://github.com/Thanatophilia/xyu-ime/actions/runs/44124429400) 全部门禁成功。
- **固定接续起点**：用户要求不从候选栏当前横滑位置接续，而是始终从候选栏处于最左端时第一屏最后一个完整候选之后开始。展开页在该输入修订首次布局时锁定此边界，横滑候选栏、收回再展开均不改变；右滑到末端或左滑回来都使用同一起点。更改拼音 / 输入修订、候选栏宽度、屏幕密度或字体缩放后重新计算。
- **横滑收回**：候选页展开时，顶部候选栏开始向任一方向横滑，即沿原有 180ms 抽屉动画收回；候选栏继续滑动，不改编码、不选词。收回中保持原候选页内容，普通键盘在动画结束后恢复。收回动作即时处理且绑定当前输入修订，重复拖动不会重新打开页面。
- **边界与编号**：右侧半露词不跳过，仍作为展开页首项；候选追加不改变已锁定起点，原始候选编号、筛选、纵向滚动位置及同一组合收回再展开的浏览位置保持。候选页内部纵向滑动、拼音栏滚动及上下图标滚屏不触发收回。
- **布局尺寸**：普通键盘符号（!@#）键与回车键同宽同高；候选页左侧拼音区域与符号键等宽，右侧功能栏和四个按钮的实际宽度均与普通回车键相同。单字模式每行五个；“全部”模式按实际文字宽度紧凑混排，二至五字词自然换行，长词最多占满一行，完整结果连续滑动。
- 候选页继续左侧首音节筛选、左下固定“全部／单字”切换，右栏自上而下为删除、上箭头、下箭头、回车图标，保留无障碍说明。
- **连续手动滑动恢复**：完整筛选列表直接交给 LazyVerticalGrid，不切固定数量页面。上下箭头从当前手动滚动位置平滑滚动约 85% 视口，保留少量重叠；按钮和手势操作同一滚动状态，手指开始拖动会取消尚未完成的按钮滚动。接近列表末端继续加载，沿用 4096 项前缀上限，不向 Rime 发送翻页键，不改编码或高亮。筛选和输入变化回顶，同组合收回再展开保留位置。候选点击与回车、删除的会话保护沿用既有实现。
- 独立悬浮编码、固定顶部候选栏、候选页展开替换整个下方键盘（包括原底部七键）的结构保留；本轮只改 app 模块与回归测试，引擎、方案、资源和构建流程未修改。

## APK 云端构建

在 [Actions → Android APK](https://github.com/Thanatophilia/xyu-ime/actions/workflows/android.yml) 下载成功构建的 `xyu-ime-版本号` artifact。解压后安装 `.apk`。同一签名可覆盖安装。

- 主分支代码推送、手动运行：单元测试、Android Lint、编译，然后用固定私密签名生成可安装 APK。
- PR：检查并编译调试版，不读取签名密钥。
- 安装包内附 SHA256、版本与提交编号，以及手机验收清单。
- 签名密钥通过仓库 Actions Secrets 提供：`XYU_KEYSTORE_BASE64`、`XYU_KEYSTORE_PASSWORD`、`XYU_KEY_ALIAS`。不要把密钥或口令提交到仓库。

安装后打开“絮雨输入法”，先启用、再选择絮雨，使用试打区检查。

详见 [第一阶段验收](docs/acceptance-phase1.md) 和 [Android 窗口适配](docs/android-window.md)。

```text

├── MainActivity.kt           # 启用引导与四类试打框
├── ime/
│   ├── XyuImeService.kt      # 系统输入连接、窗口与生命周期
```

阶段三已包含离线 Rime、中文预编辑和候选词；引擎代码位于 `rime-engine/`。系统英文语言子类型之外，键盘内部通过小地球切换中英文。
